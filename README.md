# 🏥 Hospital Management System

A **Hospital Management System** developed as my **1st Semester University Project**, built using **C, HTML, CSS, and XAMPP**.

This project was created to explore how a simple hospital management workflow can be turned into a functional local web-based system. The main goal was to make basic patient and doctor interactions easier, faster, and more organized.

### 💻 What I Built

The system allows a patient to:

* 🧑‍⚕️ Get a doctor assigned based on the information provided.
* 📄 Generate a simple appointment paper.
* 💰 Check the doctor's consultation fee without having to ask someone manually.
* 📝 Enter their information through a simple form.
* 💾 Store patient information locally so the hospital can maintain a record of the patient.

The project runs locally using **XAMPP**, with the website handling the user interface while the C-based logic and local data handling form the foundation of the project.

### 🧠 Built With My Own Logic + AI as a Tool

One thing I want to highlight about this project is **how I built it**.

This wasn't a project where I simply asked AI to generate everything and copied the result. I designed and developed the project myself, worked through the problems, understood the logic, and built the features step by step.

At the same time, I also wanted to adapt to the **growing era of AI**.

Instead of seeing AI as something that should replace my own work, I used it as a **tool to improve and tweak parts of my project**, help me understand certain problems, and experiment with better ways of implementing things.

So this project represents a combination of **my own programming, problem-solving, learning, experimentation, and a little help from AI**.

I believe learning how to use AI effectively is becoming an important part of programming — not to let it do everything for you, but to know **when and how to use it while still understanding what you're building.**
